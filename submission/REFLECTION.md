Anti-pattern số 5: Bỏ qua việc optimize small-file khiến hệ thống Voice AI Agent chậm và tốn kém vì dữ liệu bị chia thành hàng nghìn file nhỏ thay vì vài file lớn. Mỗi truy vấn phải mở rất nhiều file trên S3, làm tăng latency đáng kể, khiến phản hồi của agent bị lag và ảnh hưởng trực tiếp đến trải nghiệm realtime. Đồng thời, các engine như Spark, DuckDB hay Athena tốn nhiều tài nguyên để xử lý metadata hơn là dữ liệu thật, làm query chậm hơn nhiều lần. Pipeline streaming (ASR, embedding) cũng bị nghẽn do phải xử lý quá nhiều task nhỏ. Ngoài ra, chi phí tăng mạnh do số lượng request tới storage cao. Quan trọng hơn, bạn mất lợi thế tối ưu của Parquet, khiến toàn bộ hệ thống kém hiệu quả khi scale.
